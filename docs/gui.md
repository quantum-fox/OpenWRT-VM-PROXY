# Окно управления и меню в консоли

Применяется с версии **1.11.0**. Два способа управлять роутером без запоминания команд.

> **Метки.** 🖥️ **ПК · PowerShell** — команда вводится на вашем Windows-компьютере; 🖥️➜📡 **ПК ➜ роутер** — команда `ssh openwrt "…"` вводится на ПК, а выполняется на роутере; 📡 **Роутер · консоль** — вводится уже на роутере; 🖱️ двойной щелчок; 🌐 браузер. Подробнее: [where-to-run.md](where-to-run.md).

## 1. Меню в консоли роутера: команда `pw2`
Подключитесь к роутеру (🖥️ на ПК: `ssh root@10.99.77.1`; или откройте окно консоли VM) и введите уже **на роутере** (📡 **Роутер · консоль**, приглашение `root@OpenWrt:~#`):
```
pw2
```
Откроется меню с цифрами: состояние, выбор сервера для 1080/8080, выбор первого хопа для 1081/8081, российские ресурсы, AliExpress, реклама, выход для отдельных устройств, сеть (WAN и порты), частота проверок, обновление подписки и скриптов. Все пункты вызывают обычные команды ([commands.md](commands.md)), их можно вводить и вручную. Команда `pw2` появляется после обновления до 1.11.0 (`pw2-update`).

**Квадраты вместо букв на консоли VM.** Окно VirtualBox/Proxmox (физическая консоль, не SSH) не имеет русского шрифта и рисует квадраты. Начиная с 1.11.1 меню `pw2` на такой консоли само показывает текст латиницей (транслитом, флаги и эмодзи убираются); принудительно: `pw2 --lat` или `pw2 --ru`. Вывод любой другой команды можно пропустить через фильтр: `pw2-exit status | pw2-lat`. По SSH и в `pw2-gui` русский текст остаётся русским; для удобства работайте по SSH (`ssh root@10.99.77.1`), а консоль VM оставьте для аварийного входа.

## 2. Окно для Windows и Linux: `pw2-gui`
🖱️ Запускается на ПК (не на роутере): двойной щелчок по `pw2-gui.exe` / `pw2-gui.cmd` на Windows; 🐧 `sh tools/gui/pw2-gui.sh` на Linux.

Небольшая программа с окном (папка `tools/gui`). Она ничего не ставит на компьютер и не хранит пароли: по SSH вызывает те же команды роутера.

**Что нужно**
| | Windows | Linux |
|---|---|---|
| Запуск | готовый `pw2-gui.exe` из страницы релиза, или двойной щелчок по `tools\gui\pw2-gui.cmd` | `sh tools/gui/pw2-gui.sh` |
| Если без `.exe` | Python 3.8+ с python.org (при установке оставьте отметку «tcl/tk and IDLE») | `apt install python3 python3-tk openssh-client` |
| Клиент SSH | «Параметры → Приложения → Дополнительные компоненты → Клиент OpenSSH» (в Windows 10/11 обычно уже есть) | `openssh-client` |
| Вход на роутер | по ключу: кнопка «Настроить вход по ключу» (один раз спросит пароль root) | то же (выдаст команду для терминала) |

В поле вверху укажите имя роутера (`openwrt`, если настроен через `router-ssh-setup.ps1`) или `root@10.99.77.1` и нажмите «Подключиться».

**Вкладки**
- **Состояние:** версия, выбор серверов, российские ресурсы, AliExpress, реклама, WAN, порты; кнопка проверки внешних адресов портов 1080 и 1081.
- **Серверы:** два списка (выход для 1080/8080 и первый хоп для 1081/8081) с временем соединения; кнопки «Закрепить выбранный», «Следующий», «Самый быстрый», «Авто»; частота проверок. Подробности — [manual-exit.md](manual-exit.md).
- **Маршруты:** российские ресурсы (напрямую / через пул / через цепочку), AliExpress, Китай, блокировка рекламы (включить, выключить, обновить базы, разблокировать домен).
- **Устройства и сеть:** правила выхода для отдельных устройств (`pw2-device`: добавить, удалить, включить), WAN (телефон по USB или сетевая карта), подключение физического порта (`pw2-lan`). Блок **«Адрес роутера в локальной сети (LAN)»** (`pw2-lan-ip`): показать адрес, сменить (например, `192.168.1.1` → `10.99.77.1`) и подтвердить в течение 3 минут, иначе адрес сам вернётся. Для виртуального роутера на этом же компьютере адрес менять не нужно (скрипты Windows ждут `10.99.77.1`).
- **Настройка и обновление:** подписка и ваш сервер (форма вместо ответов в консоли; «Применить» или «С чистого листа»); **выбор папки со скриптами роутера** и их загрузка (то же, что `install-router.ps1` / `install-router.sh`, но без командной строки); «Обновить скрипты на роутере» (`pw2-update`); загрузка готового файла `secrets.env`; обновление подписки и пула.
- **Windows** (только на Windows): в начале показано, **что запущено на компьютере** (VM «OpenWRT», сторож, шлюз; кнопка «Обновить»), версия Windows и что на ней поддерживается. Блок «Виртуальный роутер (VM) и сторож»: «Остановить VM и сторожа» (`vm-pause`: шлюз выключается, сторож отключается, VM выключается), «Запустить VM, сторожа и шлюз» (`vm-resume`), отдельно «Отключить/Включить сторожа», «Выключить VM (мягко)», «Запустить VM без окна». Блок «Шлюз Windows»: включить/выключить, установить сторожа, подключить проводной порт (`lan-port.ps1`). Запускается от администратора (запрос UAC), скрипты берутся из `tools\windows`.

### 2.1. Руководство по окну: что делает каждый раздел

**Верхняя строка.** «Роутер» — имя из `~/.ssh/config` или `root@адрес`; «Подключиться» — запомнить и обновить данные; «Настроить вход по ключу» — один раз; **«Справка ↗» (справа вверху)** открывает в браузере эту страницу (`docs/gui.md`) на GitHub; позже будет ссылка на собственный git автора, адрес можно сменить в `config.json`, ключ `help_url`).

**«Свой выход для отдельных устройств» (вкладка «Устройства и сеть»; команда `pw2-device`).** По умолчанию все устройства сети роутера выходят в интернет **через пул** (серверы подписки, порт 1080). Здесь вы задаёте исключения: например, чтобы телевизор шёл напрямую, а рабочий ноутбук — через ваш рабочий сервер.
1. Нажмите «Добавить…». Имя — любое короткое слово латиницей (`tv`, `work-pc`). **Источник** — кого это касается: адрес (`10.99.77.120`), диапазон (`10.99.77.120-10.99.77.130`), подсеть (`10.99.88.0/24`), MAC-адрес (`aa:bb:cc:dd:ee:ff`; не меняется при смене адреса) или `if:порт` (всё, что подключено к порту роутера). **Выход:** «Через пул» (как по умолчанию), «Рабочий сервер» (как 1081: ваш USA), «Напрямую» (мимо прокси: полезно для устройств, которым нужен российский адрес).
2. Нажмите **«Включить выбор по устройствам»** — без этого правила записаны, но не действуют. «Выключить» отключает все правила сразу (правила остаются в списке).
3. Строка «Вкл» показывает, действует ли правило. «Удалить» убирает выбранное.
Подробно о способах подключения устройств: [devices.md](devices.md).

**«Рабочий выход 1081 / 8081» (вкладка «Серверы»; команда `pw2-usa-mode`).** Рабочий выход ведёт на ваш сервер (USA) через первый хоп из пула. Кнопки: «Показать состояние» (какой выход сейчас: основной или запасной, включено ли автопереключение), «Основной (авто…)» — обычный режим (при отказе основного порт сам переходит на запасной USA из подписки и обратно), «Закрепить запасной» — вручную только запасной, «Основной USA через первый хоп» / «напрямую (без хопа)» — идти к рабочему серверу через промежуточный сервер пула или с роутера сам (**версия скриптов 1.11.3**, не проверялось на живом роутере). Смена перезапускает PassWall2 (~10 с).

**Диагностика «нет интернета».** Кнопка есть на вкладке «Состояние» и «Настройка и обновление»: выполняет `pw2-diag` на роутере и показывает отчёт (без паролей и ссылок подписки). На роутерах со старыми скриптами команды `pw2-diag` в `/usr/bin` нет: окно тогда запускает копию из `/usr/share/pw2`, а если и её нет — подсказывает обновить скрипты (см. следующий абзац).

**Обновление роутера из окна (вкладка «Настройка и обновление»).** В поле «Папка со скриптами роутера» укажите папку **`tools\router`** из распакованного релиза (в ней лежат `pw2-setup`, `pw2-update`, `VERSION`, `01-…sh` и подпапка `data`). Если окно запущено из папки `OpenWRT-VM-PROXY\tools\gui`, поле уже заполнено. Затем: «Загрузить скрипты на роутер» (после загрузки окно проверяет роутер и **предлагает удалить остатки старых версий**: файлы `/usr/share/pw2` и `/usr/bin/pw2-*`, которых нет в загруженной папке; без вашего согласия ничего не удаляется) → «Что будет обновлено» (какие шаги выполнятся) → «Обновить скрипты на роутере». Настройки, подписка и ссылки не затираются.

**Адреса сетевых адаптеров этого компьютера (вкладка «Windows»).** Выберите адаптер в списке (Ethernet, Wi-Fi, Host-Only…): показаны адрес, шлюз, DNS, DHCP это или статический. Введите новые значения (префикс `24` = маска `255.255.255.0`; можно ввести и маску) или отметьте «Получать автоматически (DHCP)» и нажмите «Применить» (запрос администратора). **Журнал прежних адресов** хранит строки «когда / адаптер / было»: «Вернуть выбранное» возвращает записанные настройки (текущие при этом сами попадают в журнал), «Удалить выбранные строки» и «Очистить журнал» убирают лишнее (в файле `ip-log.json` рядом с `config.json` хранятся не более 50 записей). Не меняйте адрес адаптера, по которому вы сейчас связаны с роутером, если не уверены: связь пропадёт (вернуть можно из журнала).

**Что из документации уже есть в окне.** Если в документах указан способ «в окне pw2-gui», он повторяет команду из таблицы:
| Действие | Команда | Где в окне |
|---|---|---|
| Выбор/закрепление серверов | `pw2-exit` | Серверы |
| Основной/запасной рабочий выход, хоп | `pw2-usa-mode` | Серверы, блок «Рабочий выход» |
| Российские ресурсы, AliExpress, реклама, Китай | `pw2-ru-mode`, `pw2-ali-mode`, `pw2-ads`, `pw2-cn-mode` | Маршруты |
| Свой выход для устройств | `pw2-device` | Устройства и сеть |
| WAN, порты LAN | `pw2-wan`, `pw2-lan` | Устройства и сеть |
| Адрес роутера в LAN | `pw2-lan-ip` | Устройства и сеть |
| Подписка и рабочий сервер | `pw2-setup` | Настройка и обновление |
| Загрузка и обновление скриптов | `install-router.ps1`, `pw2-update` | Настройка и обновление |
| Диагностика | `pw2-diag` | Состояние; Настройка и обновление |
| VM, сторож, шлюз Windows | `vm-pause/resume`, `gateway-on/off` | Windows |
| Адреса адаптеров ПК | `netsh` (журнал в окне) | Windows |

Внизу окна — журнал: что выполнено и что ответил роутер. Каждое изменение маршрутов или серверов перезапускает PassWall2 (~10–60 с): соединения на миг обрываются.

**Первая настройка роутера:** пароль root роутер просит задать в интерактивном режиме; если он ещё не задан, программа подскажет выполнить один раз `ssh -t <роутер> pw2-setup` в терминале. После этого всё остальное, включая подписку, можно делать из окна.

## Какие версии Windows поддерживаются
| Версия | Окно управления роутером | Вкладка «Windows» (шлюз, сторож, VM) | Что нужно |
|---|---|---|---|
| Windows 10 / 11 | да | да | Python 3.8+ (или `pw2-gui.exe`), клиент OpenSSH (в Windows 10/11 обычно уже есть), VirtualBox 7.x для виртуального роутера |
| Windows 8 / 8.1 | да (не проверялось) | должны работать (PowerShell 4, сетевые команды есть), не проверялось | Python 3.8–3.11, `ssh` (Git for Windows или Win32-OpenSSH), VirtualBox 6.1 (7.x на 8.1 не поддерживается) |
| Windows 7 | да (не проверялось) | **нет**: нет сетевых команд PowerShell (`Get-NetAdapter` и др.) | Python 3.8 (последний для Windows 7), `ssh` (Git for Windows или Win32-OpenSSH). Роутер используйте физический или с другого компьютера |

Окно само определяет версию Windows и пишет подсказку на вкладке «Windows». Состояние VM, сторожа и шлюза определяется командами `VBoxManage`, `schtasks` и `route`, которые есть во всех этих версиях.

## Ограничения
- Программа проверялась на Windows 10 с Python 3.14 и с реальным роутером: чтение всех вкладок, закрепление и возврат в «авто», загрузка скриптов, правила устройств. **Не проверялись:** форма подписки, кнопки вкладки «Windows» и настройка входа по ключу. **На Linux не проверялась вообще:** окно рассчитано на стандартный tkinter, но точно сказать нельзя.
- `pw2-gui.exe` собран PyInstaller: некоторые антивирусы относятся к таким файлам с подозрением. Если это мешает, запускайте через Python (`pw2-gui.cmd`): исходный код `pw2-gui.py` — один читаемый файл.
- Окно не заменяет первую установку (создание VM, импорт образа): они описаны в [B-ready-image](../B-ready-image/README.md) и [no-windows.md](no-windows.md).
