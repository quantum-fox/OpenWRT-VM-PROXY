# Окно управления и меню в консоли

Применяется с версии **1.11.0**. Два способа управлять роутером без запоминания команд.

## 1. Меню в консоли роутера: команда `pw2`
Подключитесь к роутеру (`ssh root@10.99.77.1` или консоль VM) и введите:
```
pw2
```
Откроется меню с цифрами: состояние, выбор сервера для 1080/8080, выбор первого хопа для 1081/8081, российские ресурсы, AliExpress, реклама, выход для отдельных устройств, сеть (WAN и порты), частота проверок, обновление подписки и скриптов. Все пункты вызывают обычные команды ([commands.md](commands.md)), их можно вводить и вручную. Команда `pw2` появляется после обновления до 1.11.0 (`pw2-update`).

## 2. Окно для Windows и Linux: `pw2-gui`
Небольшая программа с окном (папка `tools/gui`). Она ничего не ставит на компьютер и не хранит пароли: по SSH вызывает те же команды роутера.

**Что нужно**
| | Windows | Linux |
|---|---|---|
| Запуск | готовый `pw2-gui.exe` из страницы релиза, или двойной щелчок по `tools\gui\pw2-gui.cmd` | `sh tools/gui/pw2-gui.sh` |
| Если без `.exe` | Python 3.8+ с python.org (при установке оставьте отметку «tcl/tk and IDLE») | `apt install python3 python3-tk openssh-client` |
| Клиент SSH | «Параметры → Приложения → Дополнительные компоненты → Клиент OpenSSH» (в Windows 10/11 обычно уже есть) | `openssh-client` |
| Вход на роутер | по ключу: кнопка «Настроить вход по ключу» (один раз спросит пароль root) | то же (выдаст команду для терминала) |

В поле вверху укажите имя роутера (`openwrt`, если настроен через `router-ssh-setup.ps1`) или `root@10.99.77.1` и нажмите «Подключиться».

**Вкладки**
- **Состояние:** версия, выбор серверов, российские ресурсы, AliExpress, реклама, WAN, порты; кнопка проверки внешних адресов портов 1080 и 1081.
- **Серверы:** два списка (выход для 1080/8080 и первый хоп для 1081/8081) с временем соединения; кнопки «Закрепить выбранный», «Следующий», «Самый быстрый», «Авто»; частота проверок. Подробности — [manual-exit.md](manual-exit.md).
- **Маршруты:** российские ресурсы (напрямую / через пул / через цепочку), AliExpress, Китай, блокировка рекламы (включить, выключить, обновить базы, разблокировать домен).
- **Устройства и сеть:** правила выхода для отдельных устройств (`pw2-device`: добавить, удалить, включить), WAN (телефон по USB или сетевая карта), подключение физического порта (`pw2-lan`).
- **Настройка и обновление:** подписка и ваш сервер (форма вместо ответов в консоли; «Применить» или «С чистого листа»); **выбор папки со скриптами роутера** и их загрузка (то же, что `install-router.ps1` / `install-router.sh`, но без командной строки); «Обновить скрипты на роутере» (`pw2-update`); загрузка готового файла `secrets.env`; обновление подписки и пула.
- **Windows** (только на Windows): шлюз Windows (включить, выключить), сторож, подключение проводного порта (`lan-port.ps1`). Запускается от администратора (запрос UAC), скрипты берутся из `tools\windows`.

Внизу окна — журнал: что выполнено и что ответил роутер. Каждое изменение маршрутов или серверов перезапускает PassWall2 (~10–60 с): соединения на миг обрываются.

**Первая настройка роутера:** пароль root роутер просит задать в интерактивном режиме; если он ещё не задан, программа подскажет выполнить один раз `ssh -t <роутер> pw2-setup` в терминале. После этого всё остальное, включая подписку, можно делать из окна.

## Ограничения
- Программа проверялась на Windows 10 с Python 3.14 и с реальным роутером: чтение всех вкладок, закрепление и возврат в «авто», загрузка скриптов, правила устройств. **Не проверялись:** форма подписки, кнопки вкладки «Windows» и настройка входа по ключу. **На Linux не проверялась вообще:** окно рассчитано на стандартный tkinter, но точно сказать нельзя.
- `pw2-gui.exe` собран PyInstaller: некоторые антивирусы относятся к таким файлам с подозрением. Если это мешает, запускайте через Python (`pw2-gui.cmd`): исходный код `pw2-gui.py` — один читаемый файл.
- Окно не заменяет первую установку (создание VM, импорт образа): они описаны в [B-ready-image](../B-ready-image/README.md) и [no-windows.md](no-windows.md).
