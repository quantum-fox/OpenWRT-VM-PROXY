# Выбор сервера вручную, закрепление и частота проверок

Применяется с версии **1.11.0**. Команда `pw2-exit` (она же пункты меню `pw2` и вкладка «Серверы» в окне [gui.md](gui.md)).

## Зачем
По умолчанию роутер сам выбирает самый быстрый сервер по пингу (балансировщик `leastPing`) и сам переключается, если сервер упал. Это удобно, но:
- выбор не всегда оптимален (по пингу, а не по реальной скорости: видео может грузиться медленно);
- при смене сервера посреди сеанса соединения рвутся, а YouTube и другие сервисы не всегда нормально на это реагируют (видео «зависает»);
- проверки всех серверов занимают процессор виртуальной машины.

Закрепление решает всё это: выбранный сервер работает **постоянно и сам не меняется**, пока вы не скажете.

## Что можно закрепить
| Что | Где используется | Команда |
|---|---|---|
| **Выход** | порты 1080/8080 и системный трафик (шлюз Windows, устройства в сети роутера) | `pw2-exit … pool` |
| **Первый хоп** | цепочка рабочего выхода 1081/8081: трафик идёт сначала на этот сервер, а затем на ваш рабочий сервер | `pw2-exit … chain` |

Закрепить можно что-то одно или оба.

## Команды
```
pw2-exit status                 что выбрано сейчас, как часто идут проверки
pw2-exit list [pool|chain]      серверы с номерами и временем соединения (мс)
pw2-exit set pool|chain СЕРВЕР  закрепить: номер из list, часть имени или ID
pw2-exit next pool|chain        перейти на следующий ДОСТУПНЫЙ сервер списка (по кругу)
pw2-exit best pool|chain        закрепить самый быстрый по времени соединения
pw2-exit auto [pool|chain]      вернуть автоматический выбор (оба, если не указано)
pw2-exit probe 2m               как часто Xray проверяет серверы пула в автоматическом режиме
pw2-exit check 10               как часто автопереключение порта 1081 проверяет рабочий выход (секунды)
```
Примеры: `pw2-exit set pool 3`, `pw2-exit set pool "LTE #5"`, `pw2-exit next chain`, `pw2-exit auto`.

После команды PassWall2 перезапускается (~10 с), текущие соединения на миг обрываются.

## Как работает
- **Сервер закрепляется по имени** (в `/etc/pw2-exit.conf`), а не по внутреннему номеру: при обновлении подписки номера серверов меняются, а имена, как правило, нет. После каждого обновления подписки `pw2-pool-sync` заново находит закреплённый сервер. **Если сервера в обновлённой подписке нет**, выбор возвращается в автоматический (запись в `/root/pw2-pool-sync.log`), чтобы не остаться без интернета.
- Для закреплённого сервера балансировщик **не используется**: нет проверок пула и нет переключений. Если сервер упал, роутер **не переключится** сам, пока вы не выберете другой (`pw2-exit next …`). Так и задумано: никаких неожиданных переключений. Если нужно, чтобы роутер сам заменил упавший сервер, оставьте автоматический выбор.
- «**Следующий доступный**»: сервер проверяется на доступность (TCP-соединение за 2 с); недоступные пропускаются. Время в `list` — это время соединения с сервером, а не скорость канала.
- Без пометки «закреплён» работает обычный балансировщик, как раньше.
- Режим «российские ресурсы через цепочку» (`pw2-ru-mode chain`) тоже начинается с вашего закреплённого выхода, если он есть.
- **Белые списки оператора:** `list` сразу показывает, какие серверы сейчас доступны (остальные — «нет ответа»); закрепите доступный, и роутер не будет тратить время на недоступные.

## Частота проверок и нагрузка
| Проверка | По умолчанию (с 1.11.0) | Было | Как менять |
|---|---|---|---|
| Проба серверов пула Xray (автоматический режим) | 2 минуты | 1 минута | `pw2-exit probe 5m` |
| Автопереключение порта 1081 (запрос через рабочий выход) | 10 секунд | 5 секунд | `pw2-exit check 20` |

Реже проверки — меньше нагрузка на виртуальную машину, но дольше обнаруживается отказ. Закреплённый выход вообще не проверяется. При закреплении **обоих** (и выхода, и первого хопа) остаётся единственная проверка: автопереключение порта 1081 на запасной сервер. Если оно не нужно, увеличьте интервал: `pw2-exit check 60`.

## Если что-то пошло не так
- «Не найден сервер»: имя уточните по `pw2-exit list` (команда `set` принимает номер, ID или часть имени; при нескольких совпадениях покажет список).
- Закреплённый сервер недоступен: `pw2-exit next pool` (или `chain`) или `pw2-exit auto`.
- Вернуть всё как было: `pw2-exit auto`, `pw2-exit probe 1m`, `pw2-exit check 5`.
