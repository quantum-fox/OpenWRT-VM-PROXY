# Роутер без Windows (Proxmox, мини-ПК, Linux)

Применяется с версии **1.10.0**. Если роутер — отдельная машина (виртуальная на Proxmox или физический мини-ПК с OpenWrt), Windows для него не нужен: все скрипты роутера — обычные команды внутри OpenWrt, а настраивать его можно с любого компьютера по SSH. Устройства подключаются кабелем к порту роутера и получают интернет через прокси **без настройки** ([devices.md](devices.md)).

## 1. Что нужно и что не нужно
| Нужно | Не нужно (это части для Windows + VirtualBox) |
|---|---|
| OpenWrt 23.05.x на x86_64: готовый образ `pw2-router.ova` (диск внутри) или чистый образ OpenWrt + [A-from-scratch](../A-from-scratch/README.md) | `tools/windows` целиком: `vm-create`, `vm-import`, `vm-tune`, `install-router.ps1`, `gateway-on/off`, сторож, настройки Firefox и VS Code, `cn-mode.cmd` и т. п. |
| Любой компьютер с `ssh` (Linux, macOS, WSL, Git Bash) для первой настройки | Windows-шлюз: компьютер просто подключается к порту роутера и получает адрес по DHCP |
| Свободный сетевой порт для устройств (LAN) и выход в интернет (WAN: сетевая карта или телефон по USB — [proxmox-usb-modem.md](proxmox-usb-modem.md)) | |

Команды `cn-mode.cmd`, `ru-mode.cmd` и другие обёртки Windows делают то же, что и команды на роутере: `ssh root@10.99.77.1 pw2-cn-mode …`, `pw2-ru-mode …`, `pw2-ali-mode …`, `pw2-ads …`. Справочник — [commands.md](commands.md).

## 2. Установка
1. **Роутер.** Proxmox: создайте VM из образа и подключите сетевую карту LAN (`net0`) к мосту с физическим портом — [proxmox-usb-modem.md](proxmox-usb-modem.md), раздел 2, и [devices.md](devices.md), раздел 2.1. Физический мини-ПК: запишите образ OpenWrt на диск (`combined-efi`) или диск из `.ova`. В образе проекта LAN-адрес роутера `10.99.77.1/24`, пароль root `pw2-change-me`.
2. **Подключите компьютер** к LAN-порту и дождитесь адреса `10.99.77.x` по DHCP.
3. **SSH-ключ** (необязательно, но удобно; пароль root при этом спросят один раз):
```
ssh-keygen -t ed25519
cat ~/.ssh/id_ed25519.pub | ssh root@10.99.77.1 "cat >> /etc/dropbear/authorized_keys"
```
4. **Загрузите скрипты** (из папки `tools/router` продукта):
```
cd tools/router
sh install-router.sh root@10.99.77.1
```
Должно закончиться словами «Готово: скрипты загружены в /usr/share/pw2». Скрипт передаёт файлы через `ssh` (в dropbear нет sftp), приводит переводы строк к LF и ничего не ставит на компьютере.
5. **Первая настройка** (спросит пароль root, адрес подписки и ссылку вашего сервера; на каждый вопрос Enter оставляет прежнее значение):
```
ssh -t root@10.99.77.1 pw2-setup
```
6. **Проверка:** `ssh root@10.99.77.1 pw2-setup status` — у выходов 1080 и 1081 должны быть IP-адреса; с подключённого устройства `https://ifconfig.me` показывает адрес сервера из пула.

Если вместо готового образа вы ставите чистый OpenWrt, после шага 4 выполните `ssh root@10.99.77.1 "sh /usr/share/pw2/01-packages.sh"` (ставит PassWall2, Xray и остальное; нужен интернет у роутера), затем шаг 5; подробности — [A-from-scratch](../A-from-scratch/README.md).

## 3. Подключение устройств
- Подключили кабель в LAN-порт → устройство получило адрес, шлюз и DNS `10.99.77.1` → интернет идёт через прокси по правилам. Ничего настраивать не нужно.
- Ещё один физический порт отдельной сетью роутера: `ssh root@10.99.77.1 "pw2-lan add eth2"` (сеть `10.99.88.0/24`, роутер `10.99.88.1`, DHCP включён). Для устройств со статическими адресами из другой подсети задайте адрес роутера в ней: `pw2-lan add eth2 192.168.100.1/24` (DHCP на порту при этом выключен; устройства с адресами `192.168.100.x` и шлюзом `192.168.100.1` заработают без перенастройки). Убрать порт: `pw2-lan del eth2`; состояние: `pw2-lan status`.
- Свой выход для отдельных устройств и портов (пул, рабочий сервер, напрямую) — `pw2-device`, см. [devices.md](devices.md), раздел 4.
- Прокси для программ остаются: `10.99.77.1:1080` и `8080` (пул), `1081` и `8081` (рабочий выход) — независимо от прозрачного режима.

## 4. Обновление
```
cd tools/router
sh install-router.sh root@10.99.77.1
ssh root@10.99.77.1 "sh /usr/share/pw2/pw2-update"
```
Порядок и версии — [update.md](update.md).

## 5. Ограничения
- Образ проекта собран для **x86_64**. На роутерах других архитектур (ARM, MIPS) готовый образ не подойдёт, а у PassWall2 и Xray там свои пакеты (в `01-packages.sh` задаётся `ARCH`); такая установка здесь **не проверялась**. Помимо этого, домашним роутерам обычно не хватает памяти (нужно от 256 МБ ОЗУ, лучше 384–512) и места на диске (~100 МБ под пакеты и геобазы).
- Автоматического отключения прозрачного режима при сбое Xray нет: если Xray остановится, устройства в LAN останутся без интернета ([devices.md](devices.md), раздел 5). Сторож Windows (fail-open) в этом варианте не работает.
