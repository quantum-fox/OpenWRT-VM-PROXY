# Глава 16. Словарь терминов

Здесь собраны слова учебника в алфавитном порядке: коротко, одним-двумя предложениями, с номером раздела, где объяснено подробно. Если слова нет в словаре, поищите его в оглавлении или в разделе, где вы его встретили.

## А–Б

- **Администратор (права администратора)** — режим программы с расширенными правами: нужен для изменения сетевых настроек и системных задач (2.7).
- **Адаптер (сетевой адаптер, сетевая карта)** — устройство или виртуальная «карта», через которую компьютер подключается к сети (3.1, 3.12, 3.18).
- **Архив** — один файл, в который упакованы другие (`.zip`, `.tar.gz`); перед использованием нужно распаковать (2.11).
- **Балансировщик** — часть Xray, которая выбирает один сервер из нескольких, например по минимальному пингу (3.9.1, 11.1).
- **База (geosite, geoip)** — файл-справочник со списками доменов или адресов по категориям и странам (9.1).
- **Брандмауэр (файрвол)** — «сторож на входе»: правила, что пропускать в сеть и из неё (2.14, 3.8).
- **BOM** — невидимая метка в начале текстового файла, которая сообщает кодировку UTF-8; PowerShell 5.1 без неё читает русский текст неверно (2.10, 10.8).
- **BusyBox** — набор урезанных версий системных команд на роутере (10.3).

## В–Г

- **Виртуальная машина (VM)** — «компьютер внутри компьютера»: программа VirtualBox изображает отдельный компьютер со своей системой (3.12).
- **VirtualBox** — программа для виртуальных машин (3.12, 12.2).
- **Host-Only** — виртуальная сеть, видимая только вашему компьютеру и VM; это LAN нашего роутера (3.12).
- **Мост (bridge)** — режим сетевой карты VM, при котором она подключается прямо к вашей реальной сети; это WAN нашего роутера (3.12, 3.18).
- **Вебсокет (WebSocket)** — способ держать постоянное соединение через обычный веб-порт; используется для маскировки (8.3).
- **Геобаза** — см. база.
- **Гость (гостевая сеть)** — отдельная сеть для посторонних устройств (15.7).

## Д–З

- **DHCP** — служба, которая выдаёт устройствам адреса автоматически (3.6).
- **DNS** — «телефонная книга» интернета: превращает имя сайта в числовой адрес (3.7).
- **dnsmasq / dnsmasq-full** — программа роутера, раздающая DNS и DHCP; для нашего проекта нужна полная версия (10.1).
- **Dropbear** — компактный SSH-сервер на роутере, без sftp (10.4).
- **Домен** — имя сайта, например `example.com` (3.7).
- **Драйвер** — программа, которая позволяет системе работать с устройством.
- **Журнал (лог)** — текстовый файл, куда программа записывает, что происходит (6.1).
- **Загрузчик** — программа, запускающая систему при включении устройства (15.3).

## И–К

- **IP-адрес** — числовой адрес устройства в сети, например `10.99.77.1` (3.2).
- **ICMP / ping** — служебный протокол и команда «отзовись» (3.17, 7.3.2).
- **Интерфейс** — точка подключения: сетевая карта, порт, виртуальный адаптер (3.18).
- **Консоль / терминал / оболочка** — окно для ввода текстовых команд и программа внутри него (2.3).
- **Ключ (SSH-ключ)** — пара файлов (закрытый и открытый) для входа без пароля (3.11, 4).
- **Кэш** — запомненные ответы для ускорения (7.4.2).

## Л–Н

- **LAN** — «внутренняя сторона» роутера: ваша локальная сеть (3.5).
- **LuCI** — веб-интерфейс роутера OpenWrt (4).
- **Маршрут** — правило «куда отправлять пакеты для такого-то адреса» (3.4).
- **Маска подсети** — число, показывающее, какая часть адреса — «улица» (3.3).
- **MAC-адрес** — «серийный номер» сетевой карты (3.18).
- **MTU** — максимальный размер пакета; при неверном значении «зависают» большие файлы (6.10, 8.6).
- **NAT** — подмена внутренних адресов на внешний при выходе наружу (3.5).
- **Узел (нода)** — один прокси-сервер из подписки (3.9, 3.9.1).

## О–П

- **OpenWrt** — открытая система для роутеров (3.13).
- **Оверлей-сеть** — сеть, построенная «поверх» обычного интернета (Tailscale, ZeroTier и подобные) (8.3).
- **Пакет (сетевой)** — порция данных, которая передаётся по сети (3.17).
- **Пакет (программный)** — установочный файл программы для менеджера пакетов `opkg`/`apk` (10.2).
- **PassWall2** — программа на роутере, управляющая маршрутами и прокси (3.13).
- **Ping** — см. ICMP.
- **Подписка** — секретный адрес, по которому провайдер отдаёт список серверов (3.9, 3.9.1).
- **Политика выполнения** — защитная настройка PowerShell, ограничивающая запуск `.ps1` (2.8).
- **Порт** — «дверь» программы на устройстве (3.8).
- **Пул** — набор узлов, из которых роутер выбирает лучший (3.9, 3.9.1).
- **Прокси** — сервер-посредник (3.9).
- **Прозрачный режим** — перехват трафика устройств без настроек на них (3.13).

## Р–С

- **Роутер** — устройство, соединяющее сети (3.5).
- **Регулярное выражение** — шаблон для поиска в тексте (11.1.5).
- **SOCKS5** — универсальный протокол прокси, порты 1080/1081 (3.9).
- **SSH** — защищённый доступ к командной строке удалённого устройства (3.11, 4).
- **SNI** — имя сайта, которое передаётся в начале HTTPS-соединения (3.16, 8.2.2).
- **Сертификат** — электронное «удостоверение» сайта (3.16).
- **Сторож (watchdog)** — задание Windows, проверяющее и поддерживающее шлюз и VM (13.1).
- **Подсеть** — отдельный «район» адресов (3.3).
- **Служба** — программа, работающая в фоне (2.12).

## Т–Я

- **TCP / UDP** — два основных способа передачи данных (3.17).
- **ТСПУ** — технические средства противодействия угрозам: оборудование операторов, анализирующее трафик (8.1).
- **TLS / HTTPS** — шифрование соединения с сайтом (3.16).
- **TUN** — виртуальный сетевой адаптер, перехватывающий весь трафик (3.15, 10.7).
- **Тоннель** — шифрованный канал между двумя точками сети (3.15).
- **Узел-хаб** — сервер с постоянным адресом, куда подключаются офисы (8.2).
- **UAC** — запрос Windows на подтверждение прав администратора (2.7).
- **UTF-8** — кодировка текста, понимающая русские буквы (2.10).
- **Фид** — источник пакетов для менеджера пакетов (10.2).
- **WAN** — «внешняя сторона» роутера: откуда приходит интернет (3.5).
- **Fail-open** — принцип «при отказе роутера пускать интернет напрямую» (13.1).
- **Fingerprint (отпечаток)** — характерные признаки соединения, по которым его опознают (8.2.2).
- **Хоп** — промежуточный сервер на пути (3.9.1, 11.1).
- **Шлюз** — устройство, куда отправляется всё, что не из вашей сети (3.4); **шлюз Windows** — режим проекта, при котором весь трафик идёт на наш роутер (13.1).
- **Xray** — программа внутри PassWall2, пересылающая трафик по правилам (3.13).
- **VLESS / Reality** — протокол прокси и способ его маскировки (3.9, 8.2.2).
- **WireGuard** — быстрый VPN-протокол (8.3).
- **Хост** — устройство в сети (3.1).
- **Шифрование** — превращение данных в нечитаемые без ключа (3.16).
