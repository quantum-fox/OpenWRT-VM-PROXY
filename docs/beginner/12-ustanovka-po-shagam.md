# Глава 12. Установка по шагам: вариант A («с нуля») и вариант B («готовый образ»)

Здесь мы проходим установку за руку. Источник — документы [A-from-scratch/README.md](../A-from-scratch/README.md) и [B-ready-image/README.md](../B-ready-image/README.md): все команды из них проверены на практике, мы лишь объясняем, **что каждая делает, что должно получиться и что делать, если нет**. Разбор неполадок установки — глава 5 (каждая неполадка там привязана к своему шагу).

> **О достоверности.** Команды, описанные ниже, взяты из документов проекта. Пояснения «что такое…» и «зачем…» — общие знания автора учебника; их нужно понимать как объяснения, а не как проверенные факты о вашем конкретном компьютере.

## 12.1. Выберите вариант

| | Вариант A: с нуля | Вариант B: готовый образ |
|---|---|---|
| Что это | скрипты сами скачивают OpenWrt и всё ставят | вы импортируете уже собранную виртуальную машину (VM) |
| Время | ~40 минут (из них ~10 просто ждёте) | ~15 минут |
| Нужен интернет | да, для скачивания образа и пакетов | да, для скачивания подписки (образ скачивается заранее) |
| Файл образа | не нужен | `pw2-router.ova` (~35 МБ) со страницы релиза («Releases») |
| Что получите | один и тот же результат | один и тот же результат |
| Кому подходит | вы хотите понимать, из чего собрано, или нужна свежая сборка | вам важна скорость и простота |

Если вы новичок — берите **вариант B**. Вариант A полезен, когда образа нет под рукой или хочется собрать самому.

## 12.2. Что понадобится до начала (общий список)

1. **Компьютер с Windows 10/11** (глава 2.15; на Windows 7/8 установка скриптами не проверялась и поддерживается ограниченно).
2. **VirtualBox** — программа для виртуальных машин (3.12). Установите с сайта virtualbox.org. Для разных версий Windows подходят разные версии VirtualBox (Windows 10/11 — 7.x).
3. **Права администратора** (2.7).
4. **Доступ в интернет** на компьютере.
5. **Данные от провайдера прокси**: адрес подписки (`https://…`), ссылка `vless://…` вашего рабочего сервера (для Reality — обязательно с `flow=xtls-rprx-vision`, если сервер его требует), по желанию — вторая ссылка для общего пула. Если вы знаете, что это, но у вас их нет, сначала получите (глава 3.9, 3.9.1).
6. **Папка продукта** `OpenWRT-VM-PROXY` на диске (распакованный архив). Далее: `<папка OpenWRT-VM-PROXY>`.

### Как запустить PowerShell от администратора

Нажмите **Пуск**, наберите `PowerShell`, правой кнопкой по «Windows PowerShell» → **«Запуск от имени администратора»** → «Да» в запросе UAC (2.4, 2.7). В заголовке окна появится слово «Администратор».

### Как перейти в папку со скриптами

🖥️ **ПК · PowerShell (админ)**
```powershell
cd <папка OpenWRT-VM-PROXY>\tools\windows
```
Подставьте реальный путь, например `cd D:\OpenWRT-VM-PROXY\tools\windows`. Если путь содержит пробелы, возьмите его в кавычки: `cd "D:\Мои документы\OpenWRT-VM-PROXY\tools\windows"`. Проверьте, что вы в нужной папке: `dir` должен показать файлы `vm-create.ps1`, `gateway-on.ps1` и другие.

### Если PowerShell не запускает скрипт

Если на `.ps1` отвечает «выполнение сценариев отключено», вы встретили политику выполнения (2.8). Два способа: запускать так — `powershell -ExecutionPolicy Bypass -File .\имя.ps1`, либо один раз разрешить для себя: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

## 12.3. Вариант B: готовый образ

### Шаг 0. Получите образ

Если вы получили продукт архивом `OpenWRT-VM-PROXY-<версия>.zip`, файл `image\pw2-router.ova` уже внутри. Если скачали репозиторий с GitHub — образа там нет: скачайте `pw2-router.ova` и `pw2-router.ova.sha256` со страницы «Releases» и положите в папку `image` (рядом с файлом `image/README.md`). Файл `.sha256` нужен для проверки целостности: скрипт сам сверит «отпечаток» образа с записанным (2.11) и откажется, если файл повреждён.

Что внутри образа: OpenWrt 23.05.6, диск 3 ГБ, PassWall2 с xray-core, **готовые пул, порты 1080/1081/8080/8081, правила по странам, блокировка рекламы**. Данные — **заглушки** (подписка `example.invalid`, узлы `placeholder-1…5`). Ваших данных и чужих секретов в образе нет. Пароль `root` по умолчанию — `pw2-change-me`: `pw2-setup` потребует его сменить.

### Шаг 1. Импорт

🖥️ **ПК · PowerShell (админ)**, в папке `tools\windows`:
```powershell
.\vm-import.ps1
```

**Что делает.** Проверяет контрольную сумму; создаёт сетевой адаптер Host-Only с адресом компьютера `10.99.77.2/24` (это «локальная сеть» роутера, 3.12); импортирует VM с именем `OpenWRT`; привязывает сети: первая карта (nic1) — Host-Only, вторая (nic2) — мост на ваш внешний адаптер (откуда роутер получит интернет). Внешний адаптер выбирается автоматически; если ошибся — укажите вручную `-WanAdapter "<имя из VBoxManage list bridgedifs>"`.

**Что должно получиться.** Сообщение об успешном импорте; в VirtualBox появилась VM «OpenWRT». **Если не так:** глава 5, разделы про импорт и адаптеры.

### Шаг 2. Запуск VM

🖥️ **ПК · PowerShell**
```powershell
& "C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" startvm OpenWRT --type headless
Test-Connection 10.99.77.1 -Count 2 -Quiet      # через ~1 минуту: True
```

**Что значит.** `&` — запустить программу по пути в кавычках. `VBoxManage` — командная утилита VirtualBox. `startvm OpenWRT --type headless` — запустить VM «без окна» (`headless`, «безголовый» режим). `Test-Connection … -Quiet` — «ответил ли адрес»: `True` — да, `False` — нет. Пока роутер загружается (до минуты), будет `False`: подождите и повторите.

### Шаг 3. Вход по SSH-ключу

🖥️ **ПК · PowerShell (админ)**
```powershell
.\router-ssh-setup.ps1 -Password pw2-change-me
```

**Что делает.** Создаёт ключ `%USERPROFILE%\.ssh\openwrt_router`, добавляет в `%USERPROFILE%\.ssh\config` короткое имя `openwrt`, и кладёт ключ на роутер. После этого вход без пароля: `ssh openwrt`. Что такое SSH и ключ — 3.11 и глава 4.

**Проверка:** 🖥️➜📡
```powershell
ssh openwrt uname -a
```
Должна вернуться строка с `Linux OpenWrt …`. **Если спрашивает пароль или отвечает ошибкой** — глава 4, таблица сообщений.

### Шаг 4. Ваши данные

🖥️➜📡 **ПК ➜ роутер**
```powershell
ssh -t openwrt pw2-setup
```

`-t` нужен, чтобы роутер мог задавать вопросы в вашем окне. Скрипт:

1. просит задать **новый пароль root** (введите дважды; символы не видны — это нормально, 4.1);
2. спрашивает **адрес подписки**, **ссылку рабочего сервера**, (необязательно) **ссылку второго сервера** (Enter, чтобы пропустить);
3. сохраняет их в `/root/secrets.env` (права 600: читать может только root);
4. скачивает подписку, заменяет заглушки вашими узлами, перестраивает пул, цепочку, правила, прозрачный режим, файрвол и сторож;
5. печатает проверку.

Повторить без вопросов: `ssh openwrt pw2-setup apply` (применит файл `/root/secrets.env`; удобно после правки файла).

### Шаг 5. Проверка

🖥️➜📡 и 🖥️
```powershell
ssh openwrt pw2-setup status
curl.exe -x socks5h://10.99.77.1:1080 https://icanhazip.com      # IP узла пула
curl.exe -x socks5h://10.99.77.1:1081 https://icanhazip.com      # IP ВАШЕГО сервера
```

Что значит: первая команда — сводка состояния; вторая и третья спрашивают у внешнего сайта «какой у меня адрес», пройдя через прокси-порт (3.14). **Ожидается:** по порту 1080 — адрес любого узла подписки; по 1081 — адрес **вашего сервера**; в сводке `автопереключение 1081: 1` (если в подписке есть узел с `USA` в названии), `cn-watch: running`, `ua_block: 1`. Если выход 1081 пустой — глава 6 и 5.

### Шаг 6. Проверьте версию

🖥️➜📡 `ssh openwrt pw2-update status`. Образ собран на версии скриптов **1.11.0**; если вышли новые — [update.md](update.md) (в окне `pw2-gui` — вкладка «Настройка и обновление»).

### Шаг 7. Обслуживание и копия

- Обновить скрипты из этой папки: 🖥️ `.\install-router.ps1`, затем 🖥️➜📡 `ssh openwrt pw2-setup apply`.
- Пакеты PassWall2 и xray без причины не обновляйте: версии совместимы друг с другом.
- Резервная копия: **выключите** VM и скопируйте её диск (`%USERPROFILE%\VirtualBox VMs\OpenWRT\*.vdi`). Внимание: **в копию попадёт `/root/secrets.env`** (ваши данные), не публикуйте её.

## 12.4. Вариант A: сборка с нуля

Подготовьте данные из 12.2 (п. 5). Все команды — из папки `tools\windows` в PowerShell от администратора.

### Шаг 1. Создать VM

🖥️ **ПК · PowerShell (админ)**
```powershell
.\vm-create.ps1
```

**Что делает.** Скачивает образ OpenWrt 23.05.6 с `downloads.openwrt.org` (~11 МБ); создаёт диск 3 ГБ; создаёт VM `OpenWRT` (2 процессорных ядра, 384 МБ памяти, виртуальные устройства virtio для скорости, режим kvm); добавляет Host-Only адаптер с адресом компьютера `10.99.77.2/24` и мост на внешний адаптер. Внешний адаптер выбирается автоматически (по лучшему маршруту по умолчанию); при ошибке — `-WanAdapter "<имя из VBoxManage list bridgedifs>"`.

**Если не получилось:** нет интернета, нет VirtualBox, нет прав администратора — глава 5.

### Шаг 2. Первый запуск: адрес и пароль

🖥️ **ПК · PowerShell** — запустить VM **с окном** (в первый раз нужна консоль):
```powershell
& "C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" startvm OpenWRT --type gui
```

Откроется окно. Подождите, пока перестанут бежать строки, и нажмите **Enter** внутри окна (появится приглашение `root@OpenWrt:/#`). Это **консоль роутера** (окно VM): мышь в нём не нужна; про захват мыши и клавиатуры — глава 4.

📡 **Роутер · консоль (окно VM)**
```sh
uci set network.lan.ipaddr='10.99.77.1'; uci commit network; /etc/init.d/network restart
passwd && touch /etc/pw2-passwd.done
```

Первая строка задаёт адрес роутера в локальной сети `10.99.77.1`; вторая запрашивает новый пароль `root` (дважды; символы не видны) и ставит метку «пароль задан». **Важно:** после того как пароль задан, при следующем входе в окно VM сначала покажется строка `login:` (4.2).

Вернитесь в PowerShell на ПК и проверьте связь:

🖥️ **ПК · PowerShell**
```powershell
Test-Connection 10.99.77.1 -Count 2 -Quiet      # True
```

Окно VM можно свернуть (не закрывайте и не выключайте принудительно). Позже сторож Windows запускает VM без окна.

### Шаг 3. Вход по ключу

🖥️ **ПК · PowerShell (админ)**
```powershell
.\router-ssh-setup.ps1           # спросит пароль из шага 2
```
Проверка: 🖥️➜📡 `ssh openwrt uname -a`. Дальше все команды — `ssh openwrt …`.

### Шаг 4. Загрузить скрипты на роутер

🖥️ **ПК · PowerShell (админ)**
```powershell
.\install-router.ps1
```

Копирует папку `tools\router\*` в `/usr/share/pw2` и ставит команду `pw2-setup`. Файлы идут через SSH командой `cat` (на роутере нет `sftp`, 10.4).

### Шаг 5. Расширить диск (~5 минут)

🖥️ **ПК · PowerShell (админ)**
```powershell
.\expand-disk.ps1
```

В образе OpenWrt корневой раздел ~100 МБ: для PassWall2 мало. Скрипт **3 раза** запускает `00-expand-disk.sh` (на роутере) с двумя автоматическими перезагрузками. В конце: `ГОТОВО`, корень ~2,9 ГБ. Нужен интернет на роутере (ставятся `parted`, `e2fsprogs`, `resize2fs`, `blkid`). **Не прерывайте** процесс. Причины и устройство — [vm-settings.md](vm-settings.md).

### Шаг 6. Установить пакеты (~5 минут)

🖥️➜📡
```powershell
ssh openwrt 'sh /usr/share/pw2/01-packages.sh'
```

Ставит LuCI (веб-интерфейс), **`dnsmasq-full`** (обязателен, 10.1), подключает фид и ключ PassWall2 (русская локализация), обновляет `xray-core` (нужен 26.x), ставит модули `kmod-nft-tproxy`/`kmod-nft-socket` (прозрачный UDP). В конце печатает версии: `xray-core 26.9.x`, `luci-app-passwall2 26.10.x`.

### Шаг 7. Ввести данные и применить

🖥️➜📡
```powershell
ssh -t openwrt pw2-setup
```
Те же вопросы, что в варианте B (шаг 4). Дальше автоматически выполняются скрипты `02…08`:

| Скрипт | Что делает |
|---|---|
| `02-subscription-and-nodes.sh` | скачивает подписку, добавляет ваши узлы (`USA-via-pool`, при наличии — дополнительный) |
| `03-pool-sync-install.sh` | ставит `pw2-pool-sync` (обновление подписки и пула, раз в 6 часов) и `/etc/pw2-pool.conf` |
| `04-balancer-socks-chain.sh` | балансировщик `POOL leastPing`, цепочка «пул → ваш сервер», порты 1080/1081/8080/8081 |
| `06-routing-rules.sh` (как `pw2-routing-apply`) | правила RU/UA/CN, запасной рабочий выход, автопереключение |
| `05-transparent.sh` | прозрачный режим для клиентов локальной сети |
| `07-ua-firewall.sh` | блокировка адресов Украины (`inet ua_block`) |
| `08-cn-fallback.sh` | сторож Китая `cn-watch` и команда `pw2-cn-mode` |

Скрипты безопасно запускать повторно (`pw2-setup apply`).

### Шаг 8. Проверка

Те же три команды, что в варианте B (шаг 5), плюс:

🖥️➜📡
```powershell
ssh openwrt 'sh /usr/share/pw2/verify-usa-chain.sh'
```
Проверяет, что рабочий выход идёт через цепочку, а прямых соединений с вашим сервером нет. 🌐 **Браузер**: веб-интерфейс `http://10.99.77.1/cgi-bin/luci/admin/services/passwall2`, логин `root`.

## 12.6. Типичные ошибки новичков при установке

| Ошибка | Как избежать |
|---|---|
| Запустили PowerShell без прав администратора | заголовок окна должен содержать «Администратор» (2.7) |
| Запустили скрипт из другой папки | сначала `cd` в `tools\windows`, потом `dir` — проверьте файлы |
| Закрыли окно VM или выключили кнопкой питания во время `expand-disk.ps1` | шаг 5 нельзя прерывать |
| Вставили в `pw2-setup` ссылку с лишними пробелами или в несколько строк | ссылка — одна строка без пробелов в начале и конце |
| Забыли `flow=xtls-rprx-vision` в ссылке Reality | проверьте ссылку у провайдера сервера |
| Оставили включённым другой VPN/TUN-клиент | закройте (13.4) |
| Не дождались загрузки роутера (`False` в `Test-Connection`) | подождите минуту и повторите |
