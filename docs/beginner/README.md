# Учебник для новичков (docs for C1): как он устроен

Это **исходники** учебника: по главе в файле (`01-…md`, `02-…md`, …). Читать удобнее собранный файл **[../beginner-guide.md](../beginner-guide.md)**: в нём одно оглавление, работают все ссылки между главами и его легко печатать.

## Как собрать один файл
🖥️ **ПК · PowerShell** (нужен установленный Python):
```powershell
python docs\beginner\build.py
```
Скрипт склеивает главы по номерам и пересоздаёт `docs/beginner-guide.md`. Этот файл вручную не правится.

## Правила написания (чтобы учебник не расползался)
1. **Определение при первом упоминании.** Новое слово объясняется сразу, там, где оно впервые встретилось, в рамке «Определение». При повторных упоминаниях только ссылка на то место (`[IP-адрес](#term-ip)`). Для ссылок у определения стоит якорь `<a id="term-ip"></a>`.
2. **Простой язык.** Бытовые сравнения, никаких фраз «как известно». Если можно сказать проще, говорим проще.
3. **Каждая команда:** где вводить (метка из [where-to-run.md](../where-to-run.md)), что она делает по словам, что должно получиться, что делать, если получилось не так.
4. **Честность.** Что не проверялось на практике, так и помечается.
5. **Единый источник правды: русский текст проекта.** Изменилась команда в проекте — правим главу и пишем в `CHANGELOG.md`.
