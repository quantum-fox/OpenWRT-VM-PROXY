# Роутер на Proxmox, интернет через телефон по USB

Применяется с версии **1.8.0**. Роутер работает как виртуальная машина Proxmox VE; интернет (WAN) он получает от телефона, подключённого к серверу USB-кабелем в режиме «USB-модем». Сеть клиентов (LAN) — внутренний мост без физического порта.

```
телефон (USB-модем) ──USB-порт сервера──► VM OpenWrt (WAN = usb0) ──LAN, vmbr2 (мост без порта)──► машины-клиенты
```

## 1. Что входит в образ
- Пакеты `kmod-usb-net-rndis` (Android, режим «USB-модем» = RNDIS), `kmod-usb-net-cdc-ether` (Ethernet-режим CDC, часть телефонов и модемов), `usbutils` (команда `lsusb`).
- Драйверы USB-контроллеров (EHCI, xHCI, UHCI, OHCI) уже встроены в ядро образа x86_64, отдельно ставить не нужно.
- Команда `pw2-wan`: переключает WAN между сетевой картой и телефоном и сама подставляет интерфейс телефона при каждом подключении (его имя бывает `usb0` или `eth1`, а при переподключении может смениться).
- Образ собран на **1.8.0**; если VM создана из образа более ранней версии: загрузить скрипты (`install-router.ps1` с Windows или копированием папки `tools/router` в `/usr/share/pw2`), затем `sh /usr/share/pw2/pw2-update` — шаг 1.8.0 установит пакеты (роутеру нужен выход в интернет на время установки: например временный WAN через сетевую карту).
- Пакеты нужно положить в образ **до** отключения сетевого WAN: без интернета доустановить их нельзя.

## 2. Создание VM из образа (на хосте Proxmox, по SSH)
Образ `pw2-router.ova` — это tar-архив: внутри `.ovf` и диск `.vmdk`.
```
mkdir /root/pw2 && cd /root/pw2
tar -xf /путь/к/pw2-router.ova
ls
```
Номер VM (`110`), мост LAN (`vmbr2`) и хранилище (`local-zfs`) — ваши; **имена и номера проверьте** (`qm list`, `pvesm status`, `ip -br link`).
```
qm create 110 --name openwrt --ostype l26 --memory 384 --cores 2 --cpu host --net0 virtio,bridge=vmbr2 --onboot 1
qm importdisk 110 /root/pw2/*.vmdk local-zfs
qm set 110 --sata0 local-zfs:vm-110-disk-0 --boot order=sata0
```
Мост без физического порта (если его ещё нет) добавляется в `/etc/network/interfaces` (копия файла перед правкой обязательна):
```
auto vmbr2
iface vmbr2 inet manual
    bridge-ports none
    bridge-stp off
    bridge-fd 0
```
Применить: `ifreload -a`.

Замечания:
- Режим BIOS по умолчанию (SeaBIOS, машина i440fx) подходит: образ `combined-efi` грузится и так; диск подключён как SATA, как в VirtualBox.
- Первая сетевая карта VM (`net0`) в роутере — это **LAN** (`eth0`, адрес `10.99.77.1/24`). Вторую карту (`eth1`, прежний WAN) в этом варианте **не добавляют**: WAN — телефон.
- Сеть клиентов должна быть на том же мосте: у клиентов шлюз и DNS `10.99.77.1`, адрес из `10.99.77.0/24`.
- Консоль в Proxmox: **Console** (дисплей по умолчанию) — для первого входа и смены LAN-адреса, если нужен другой.

## 3. Передача телефона VM: по номеру USB-порта, а не по идентификатору
Идентификатор устройства (`VID:PID`) у телефона **меняется при включении режима модема**: в режиме передачи данных он один, в режиме «USB-модем» другой. Поэтому передача «по идентификатору» теряет телефон при каждом переключении режима. Передача **по порту** привязывает к физическому порту сервера и не зависит от режима телефона: то, что воткнуто в этот порт, всегда уходит VM, а при переподключении кабеля QEMU подключает устройство заново само.

1. Воткните телефон в нужный порт сервера (лучше задний порт материнской платы, не передний и не через хаб).
2. На хосте найдите путь порта:
```
lsusb -t
```
и по строкам (шина, порт: например `Bus 003 ... Port 4`) определите устройство. Надёжнее всего: `ls -l /sys/bus/usb/devices/` и найти запись вида `3-4` (шина-порт) или `1-1.4` (порт за хабом контроллера); проверка: `cat /sys/bus/usb/devices/3-4/product`.
3. Передать порт VM (формат `шина-порт`, цифры из предыдущего шага; `usb3=1` включает USB 3 контроллер xHCI):
```
qm set 110 --usb0 host=3-4,usb3=1
```
В веб-интерфейсе то же: **Hardware → Add → USB Device → Use USB Port**.
4. Если USB-устройство при передаче «пропадает» после перезагрузки **хоста**, проверьте путь заново (`lsusb -t`): номер шины зависит от порядка опроса USB-контроллеров, а при пробросе контроллеров или портов виртуальным машинам он может сдвинуться. В Proxmox VE 8 есть **USB-маппинг** (Datacenter → Resource Mappings → USB): имя устройства вместо прямой привязки; проверьте на своей версии.

Передача по порту рассчитана на горячее подключение: VM может быть запущена, телефон можно подключать и отключать (QEMU заново подключает устройство в этом порту; проверьте на своём железе).

## 4. Телефон
Android (на примере Honor 8X, оболочка EMUI; названия пунктов могут отличаться):
1. Подключите телефон кабелем к серверу (кабель с передачей данных, не только зарядный).
2. В шторке уведомлений USB: режим «Передача файлов» (на некоторых прошивках без него пункт «USB-модем» неактивен).
3. **Настройки → Беспроводные сети (или Сеть и интернет) → Режим модема → USB-модем** — включить. Пока кабель не подключён, пункт недоступен.
4. Мобильные данные на телефоне включены; режим «в самолёте» выключен.

Телефон в режиме модема сам выдаёт роутеру адрес по DHCP (обычно из `192.168.42.0/24`, шлюз `192.168.42.129`), делая для роутера NAT. Пересечения с LAN `10.99.77.0/24` нет.

## 5. Включить WAN через телефон (на роутере)
Из консоли VM или по SSH с машины-клиента:
```
pw2-wan usb
pw2-wan status
```
`pw2-wan status` показывает режим, найденный USB-модем (`usb0` или `eth1`, драйвер `rndis_host`), адрес от телефона, список USB-устройств (`lsusb`) и наличие выхода в интернет. Если телефон ещё не подключён, команда `usb` ставит WAN временно на `usb0`, а как только телефон появится, обработчик подключения подставит нужный интерфейс сам (и поднимет WAN).

Вернуть сетевую карту: `pw2-wan eth` (или `pw2-wan eth eth2` для другой карты; имя запоминается).

## 6. Проверка
1. `ssh root@10.99.77.1 pw2-wan status`: USB-модем найден, адрес есть, «выход в интернет: есть».
2. `ssh root@10.99.77.1 pw2-setup status`: выходы 1080/1081 дают IP-адреса.
3. С клиента: `curl -x socks5h://10.99.77.1:1080 https://icanhazip.com`.

## 7. Если не работает
| Симптом | Что проверить |
|---|---|
| `lsusb` на роутере не показывает телефон | на хосте `lsusb -t` видит ли телефон; верен ли путь в `qm config 110` (`usb0: host=…`); передача включена, VM перезапущена; кабель с передачей данных |
| Телефон виден, но интерфейса нет | на телефоне не включён «USB-модем»; режим модема появляется в списке `lsusb` как другой идентификатор; `dmesg` показывает `rndis_host` / `cdc_ether` |
| Интерфейс есть, адреса нет | `ifup wan`; `pw2-wan status`; на телефоне мобильные данные; перезапуск режима «USB-модем» (выключить и включить) |
| После перезагрузки VM интернета нет | `pw2-wan status`: `WAN_MODE=usb`? телефон подключён к тому же порту? |
| Пакетов нет (`pw2-wan: ... usbutils`) | `opkg update; opkg install kmod-usb-net-rndis kmod-usb-net-cdc-ether usbutils` (нужен интернет, временно WAN через сетевую карту) |
| iPhone | вместо RNDIS нужен драйвер `kmod-usb-net-ipheth` и `usbmuxd`; в образ не входит, ставится отдельно (`opkg install kmod-usb-net-ipheth usbmuxd`); не проверялось |
