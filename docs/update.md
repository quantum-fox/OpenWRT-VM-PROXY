# Обновление до новой версии

Если вы уже установили более раннюю версию (например, без блокировки рекламы), **заново ставить не нужно**: загрузите новую версию продукта и выполните одну команду обновления. Ваши данные (подписка, ссылка на сервер) и настройки сохраняются.

Что изменилось в каждой версии — [../CHANGELOG.md](../CHANGELOG.md).

## 0. Коротко
1. Скачайте новую версию продукта (раздел «Releases» репозитория или архив `OpenWRT-VM-PROXY-<версия>.zip`) и распакуйте **в новую папку**.
2. В PowerShell откройте папку `tools\windows` новой версии и выполните `.\install-router.ps1`.
3. Выполните `ssh openwrt "sh /usr/share/pw2/pw2-update"`.
4. Подождите ~2 минуты и проверьте: `ssh openwrt pw2-update status` → «обновление не требуется».
Остальное — подробности и разбор проблем.

## 1. Как устроены версии и обновления
- **Версия.** Номер `МАЖОР.МИНОР.ПАТЧ`. Файл `VERSION` в корне продукта — версия **новых** скриптов; версия, **уже установленная на роутере**, лежит в файле `/etc/pw2-version` (`ssh openwrt cat /etc/pw2-version`). Если файла нет — роутер установлен до введения версий, это `1.0.0`.
- **Обновляться можно с любой версии сразу на последнюю.** Идти по очереди `1.0 → 1.1 → 1.2` вручную не нужно: команда `pw2-update` сама выполняет **все недостающие шаги по порядку** и записывает версию после каждого шага. Если шаг не удался, она останавливается и пишет, на какой версии остановилась; после исправления причины запустите её снова — продолжит с этого места.
- **Ваши данные не затираются.** `/root/secrets.env` (подписка, ссылки) не меняется; ваши правки списков в `/etc/pw2-routing.conf` и `/etc/pw2-pool.conf` сохраняются, недостающие новые параметры дописываются.
- **Копии перед обновлением** (автоматически): `/root/passwall2.before-update-<версия>-<время>` и такие же для `network`, `dhcp`, `firewall`, `pw2-routing.conf`, `pw2-pool.conf`.
- **Интернет у роутера для обновления не нужен:** все файлы (скрипты и база рекламы) загружает `install-router.ps1` с вашего компьютера.

## 2. Что нужно обновлять и когда
| Установлено | Роутер (`install-router.ps1` + `pw2-update`) | Скрипты Windows (папка `tools\windows`) | Что изменится |
|---|---|---|---|
| `1.0.0` (нет файла версии) | да | **да** | IPv6 выключается; включается блокировка рекламы; правило AliExpress; российская база рекламы; сторож Windows сам перезапускает VM, если пропал выход в сеть |
| `1.1.0` | да | нет | российская база рекламы |
| `1.2.0`, `1.2.1` | обновление не требуется (версия 1.2.1 - только документация) | нет | — |
| образ из варианта B (`pw2-router.ova`, собран на скриптах `1.2.0`) | не требуется | нет | образ уже содержит всё; после импорта `pw2-update status` покажет «обновление не требуется» |

## 3. Порядок обновления
### Шаг 1. Подготовка
- Распакуйте новую версию продукта в **новую папку** (старую не удаляйте, пока не убедитесь, что всё работает).
- Убедитесь, что вход на роутер работает: `ssh openwrt echo ok` должно ответить `ok`. Если нет — выполните `.\router-ssh-setup.ps1` из `tools\windows` ([A-from-scratch](../A-from-scratch/README.md), шаг 3) или проверьте, что VM запущена.
- (Рекомендуется) Сделайте копию диска VM: выключите VM и скопируйте `%USERPROFILE%\VirtualBox VMs\OpenWRT\*.vdi` (копия содержит ваши данные — не публикуйте её).

### Шаг 2. Загрузить новые файлы на роутер
В PowerShell, в папке `tools\windows` **новой** версии:
```powershell
.\install-router.ps1
```
Ожидаемый вывод: `Готово: скрипты загружены в /usr/share/pw2 (NN файлов). Команда на роутере: pw2-setup`. Скрипт кладёт на роутер скрипты, файл `VERSION` и данные (`data\geosite_RU-ADS.dat`, российская база рекламы). Если скрипты не запускаются из-за политики выполнения: `powershell -ExecutionPolicy Bypass -File .\install-router.ps1`.

### Шаг 3. Посмотреть план и выполнить обновление
Команды выполняются в PowerShell на Windows. **В первый раз** команды `pw2-update` ещё нет в `/usr/bin`, поэтому она запускается из `/usr/share/pw2`:
```powershell
ssh openwrt "sh /usr/share/pw2/pw2-update status"
```
Пример вывода для версии `1.0.0`:
```
установлена версия: 1.0.0
версия скриптов:    1.2.0
будут выполнены шаги: 1.1.0 1.2.0
```
Выполнить:
```powershell
ssh openwrt "sh /usr/share/pw2/pw2-update"
```
Пример вывода (сокращённо):
```
[pw2-update] копии настроек: /root/*.before-update-1.0.0-20261006-114716
[pw2-update] шаг 1.1.0 ...
[pw2-update] шаг 1.1.0 выполнен, версия 1.1.0
[pw2-update] шаг 1.2.0 ...
[pw2-update] шаг 1.2.0 выполнен, версия 1.2.0
[pw2-update] готово: установлена версия 1.2.0
```
- **Это займёт 1-2 минуты; интернет через роутер на это время может пропасть** (PassWall2 и сеть роутера перезапускаются). В шаге `1.1.0` перезагружается сеть роутера, поэтому **SSH-соединение может оборваться — это нормально**: обновление идёт отдельным процессом и доработает само. Подождите ~2 минуты и посмотрите итог: `ssh openwrt pw2-update status` (должно быть «обновление не требуется»); полный журнал: `ssh openwrt cat /root/pw2-update.log`.
- Дальше команда доступна просто как `pw2-update` (`ssh openwrt pw2-update status`).

### Шаг 4. Проверить результат
```powershell
ssh openwrt pw2-update status        # установлена версия = версии скриптов; "обновление не требуется"
ssh openwrt pw2-setup status         # выходы 1080 и 1081 заданы (IP-адреса)
ssh openwrt pw2-ads status           # блокировка рекламы: ВКЛ
ssh openwrt pw2-ipv6 status          # всё "ВЫКЛ-ok" / "нет-ok"
curl.exe -x http://10.99.77.1:8080 https://icanhazip.com        # IP узла пула
curl.exe -s -o NUL -w "%{http_code}" -x http://10.99.77.1:8080 http://doubleclick.net/   # 503: реклама блокируется
```
Если сразу после обновления выходы пустые, подождите минуту: пул выбирает лучший узел по пингу (проба раз в минуту).

### Шаг 5. Скрипты Windows (если в таблице выше «да»)
Скрипты Windows — это папка `tools\windows`: шлюз, сторож, настройка браузера и т. п. После обновления с `1.0.0`:
- **Если вы распаковали новую версию в ту же папку** (заменили файлы) — больше ничего не нужно: сторож подхватит новые файлы сам в течение минуты.
- **Если новая версия лежит в другой папке** — от администратора выполните `.\install-watchdog-task.ps1` из `tools\windows` **новой** папки: задача сторожа пересоздаётся с путём к новым скриптам. Старую папку можно удалить после проверки (`Get-ScheduledTask OpenWRT-Gateway-Watchdog` и лог `C:\ProgramData\win-gateway\watchdog.log`).
Если у вас уже включён прозрачный шлюз, он останется включённым.

## 4. Что нового получает пользователь версии 1.0.0
IPv6 выключен; включена блокировка рекламы (`pw2-ads status`; выключить — `pw2-ads off`, разблокировать свой домен — `pw2-ads allow <домен>`); AliExpress и Alibaba идут отдельным правилом (`pw2-ali-mode status`); загружена российская база рекламы (~149 тыс. доменов); сторож Windows перезапускает VM при пропаже выхода в сеть. Подробности и настройка — [routing-rules.md](routing-rules.md), команды — [commands.md](commands.md).

## 5. Если что-то пошло не так
| Симптом | Что делать |
|---|---|
| `ssh openwrt` не отвечает после обновления | подождите 2-3 минуты (идёт перезапуск сети); проверьте, что VM запущена; при необходимости — окно VM: `VBoxManage startvm OpenWRT --type gui`, войдите `root` и `ip -4 a`: у `br-lan` должен быть `10.99.77.1/24` ([troubleshooting.md](troubleshooting.md)) |
| `pw2-update`: «нет /usr/share/pw2/VERSION» | не выполнен шаг 2: `.\install-router.ps1` |
| `pw2-update`: «НЕ выполнен - остановлено на версии …» | прочитайте причину в журнале `ssh openwrt cat /root/pw2-update.log`, устраните и запустите `pw2-update` ещё раз (продолжит с места остановки) |
| Реклама блокируется слишком сильно (сайт не открывается) | `ssh openwrt pw2-ads off` (временно) или `ssh openwrt pw2-ads allow <домен>` |
| Всё плохо, нужно вернуться | см. «Откат» ниже |

### Откат
1. Вернуть настройки: зайдите на роутер `ssh openwrt` и скопируйте файлы из копий, например: `cp /root/passwall2.before-update-1.0.0-<время> /etc/config/passwall2`; так же для `network`, `dhcp`, `firewall`, `pw2-routing.conf` (`/etc/pw2-routing.conf`), `pw2-pool.conf` (`/etc/pw2-pool.conf`). Затем `/etc/init.d/network restart` и `/etc/init.d/passwall2 restart`. Если связь с роутером пропала — те же команды в консоли VM (окно VirtualBox).
2. Вернуть версию, если хотите повторить шаги: `ssh openwrt "echo 1.0.0 > /etc/pw2-version"` и снова `pw2-update`.
3. Отдельно: только реклама — `pw2-ads off`; только IPv6 — `pw2-ipv6 on`.
4. Полный откат — вернуть сохранённую копию диска VM (шаг 1) и старую папку со скриптами.
