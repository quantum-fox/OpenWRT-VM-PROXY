# Физический роутер вместо виртуальной машины (на примере Netis NX31)

Применяется с версии **1.11.2**. Те же скрипты и те же настройки работают на настоящем роутере с OpenWrt 24.10 (проверено на NX31: MT7981, aarch64, без USB). Ничего собирать не нужно: ставится чистая OpenWrt, затем скрипты проекта.

> **Метки.** 🖥️ **ПК · PowerShell** — команда вводится на вашем Windows-компьютере; 🖥️➜📡 **ПК ➜ роутер** — команда `ssh openwrt "…"` вводится на ПК, а выполняется на роутере; 📡 **Роутер · консоль** — вводится уже на роутере; 🖱️ двойной щелчок; 🌐 браузер. Подробнее: [where-to-run.md](where-to-run.md).

Дополнительная метка: 🐧 **ПК · терминал** — Linux, macOS или Git Bash (для `install-router.sh`).

## 1. Что нужно от роутера
- OpenWrt 24.10 или новее и достаточно памяти (NX31: 256 МБ ОЗУ, 128 МБ флеш; пул, база рекламы и Xray помещаются свободно).
- Архитектура и версия определяются сами (`01-packages.sh` читает `/etc/openwrt_release`), фид PassWall2 берётся под них.
- Порты: у роутера свой набор (NX31: `lan1`–`lan3` и `wan`, а не `eth0/eth1`). Если пользуетесь `pw2-lan`/`pw2-wan`, указывайте имена портов из `ip link` на этом роутере.

## 2. Установка (после того, как на роутере чистая OpenWrt и есть интернет по WAN)
Первая строка — 🐧 **ПК · терминал** (скрипт `install-router.sh` запускается на ПК, не на роутере; на Windows вместо него — 🖥️ `install-router.ps1`); вторая — 🖥️➜📡 **ПК ➜ роутер**:
```
sh install-router.sh root@192.168.1.1       # загрузить скрипты (из папки tools/router)
ssh -t root@192.168.1.1 pw2-setup            # спросит пароль root, адрес подписки, ссылку рабочего сервера
```
Прошивка роутера (замена загрузчика, TFTP) описана на странице устройства в таблице OpenWrt: **перед прошивкой снимите копии всех разделов флеша** (`/proc/mtd`), особенно `Factory` (калибровка Wi-Fi уникальна для каждого роутера).

## 3. Адрес роутера в сети (LAN)
Чистая OpenWrt занимает `192.168.1.1`. В виртуальной версии проекта роутер имеет `10.99.77.1`. Чтобы на физическом роутере было так же. Шаги 1, 2, 4 — 🖥️ **ПК**; шаги на роутере — 📡; `ssh` — с ПК:
```
pw2-lan-ip status                 # сейчас
pw2-lan-ip set 10.99.77.1         # применится через 3 с; ждёт подтверждения 3 минуты
# на компьютере: обновить адрес (отключить/подключить кабель или Wi-Fi), затем:
ssh root@10.99.77.1
pw2-lan-ip keep                   # подтвердить, иначе адрес сам вернётся на старый
```
`pw2-lan-ip set АДРЕС --now` меняет без отката (только если подключены кабелем и уверены). Вручную то же самое: `uci set network.lan.ipaddr=10.99.77.1; uci commit network; /etc/init.d/network restart`.

Подсеть LAN не должна совпадать с подсетью WAN (скрипт откажется). Если в сети уже есть другой роутер с `10.99.77.1` (например, виртуальная версия в Proxmox), не включайте оба в один сегмент.

## 4. Ноутбук с виртуальным роутером и физический роутер
Когда ноутбук должен работать через физический роутер, а VM OpenWrt при этом не нужна:
- `tools\windows\vm-pause.cmd` — выключает шлюз Windows, отключает сторож, выключает VM и **выключает адаптер Host-Only 10.99.77.x** (иначе, если у физического роутера тоже `10.99.77.x`, два адаптера в одной подсети ломают выход в интернет).
- `tools\windows\vm-resume.cmd` — всё возвращает (включает адаптер, сторож, VM и шлюз).

## 5. Wi-Fi
По умолчанию на чистой OpenWrt Wi-Fi выключен. Включить (📡 **Роутер · консоль**): `uci set wireless.radio0.disabled=0; uci set wireless.radio1.disabled=0`, задать `wireless.default_radioN.encryption=psk2` и `key`, затем `uci commit wireless; wifi reload`. Не оставляйте сеть открытой: клиенты Wi-Fi попадают в тот же прозрачный прокси и пользуются вашей подпиской.
