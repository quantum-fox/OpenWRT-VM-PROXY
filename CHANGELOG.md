# История версий

Версия продукта записана в файле `VERSION` (в корне этой папки) и на роутере в `/etc/pw2-version`. Как обновиться — [docs/update.md](docs/update.md).
Формат номера `МАЖОР.МИНОР.ПАТЧ`: **патч** — исправления и документация без изменений настроек; **минор** — новые возможности (нужен шаг обновления); **мажор** — несовместимые изменения (обновляться по инструкции версии).

## 1.6.0 — 2026-10-16
- **Переключатель «российские ресурсы напрямую / через прокси» — `pw2-ru-mode`.** Раньше правило RU было жёстко «напрямую», а при белых списках мобильного оператора часть российских сайтов (и сайты на любых зонах с российскими IP) напрямую не открывается. Теперь одна команда меняет маршрут **всех** российских ресурсов сразу (домены `.ru/.su/.рф`, российские сайты на любых зонах, IP России): `pw2-ru-mode direct` (по умолчанию, как раньше), `pw2-ru-mode proxy` (всё через пул), `pw2-ru-mode node ID` (через конкретный узел), `pw2-ru-mode status`. Переменная `RU_ACTION` в `/etc/pw2-routing.conf`. Порты 1081/8081 не затрагиваются (российские ресурсы там блокируются всегда).
- С Windows: `tools\windowsu-mode.cmd` и «кнопки» двойным щелчком: `ru-direct.cmd`, `ru-proxy.cmd`.
- Шаг обновления: `1.5.x → 1.6.0` (ставит команду, добавляет `RU_ACTION="_direct"`; поведение по умолчанию не меняется).

## 1.5.1 — 2026-10-16
- Исправлена команда `pw2-chain-bench` (замер цепочки): при обрыве SSH она могла оставить временные узлы `bench-tstn0…5` и порты 1190-1195 (6 лишних процессов Xray, порты были открыты для всей локальной сети). Теперь скрипт убирает их и при обрыве, и при следующем запуске, а порты слушает только на самом роутере.
- Шаг обновления `1.5.0 → 1.5.1` удаляет такие остатки, если они уже есть; `pw2-setup reset` тоже их убирает. Проверить у себя: `ssh openwrt "uci show passwall2 | grep bench"` - вывод должен быть пустым.

## 1.5.0 — 2026-10-15
- **Подписка с «заглушкой» провайдера.** Некоторые провайдеры (например капибара) вместо узлов отдают один ответ «Данное приложение не поддерживается», если клиент им незнаком. Теперь `pw2-setup` сам перебирает имена клиента (User-Agent: по умолчанию, `v2rayN/7.0`, `Happ/2.0`, `clash-verge/v1.7.7`, `Hiddify/2.0`, `sing-box`, `passwall2`), оставляет то, при котором пришли настоящие узлы (оно записывается в настройки подписки и используется при каждом обновлении пула), и удаляет узлы-заглушки.
- **`pw2-setup reset`:** начать настройку узлов и подписки с чистого листа (удаляет все старые узлы и подписки, кроме служебных; копия настроек сохраняется в `/root/passwall2.before-reset-*`), затем спрашивает данные и применяет всё заново. Для тех, у кого узлы добавлены вручную в LuCI и всё запуталось.
- Шаг обновления: `1.4.x → 1.5.0` (ставит новые команды). Образ `pw2-router.ova` пересобран на 1.5.0.

## 1.4.0 — 2026-10-12
- Новая команда **`pw2-ads update`**: роутер сам скачивает свежие базы рекламы (`geosite_ADS-GLOBAL.dat`, `geosite_ADS-RU.dat`) из последнего релиза репозитория `OpenWRT-VM-PROXY-ads` (адрес - `ADS_UPDATE_URL` в `/etc/pw2-routing.conf`), проверяет SHA256, подключает и применяет правила. Сначала пробует напрямую, затем через свой прокси 8080. Файлы баз в репозиториях лежат в Releases, а не в Git.
- Шаг обновления: `1.3.x → 1.4.0` (ставит команду, добавляет `ADS_UPDATE_URL`).

## 1.3.0 — 2026-10-12
- **Полная база рекламы и трекеров (~205 тыс. доменов)** вместо одной российской: два файла данных `geosite_ADS-GLOBAL.dat` (зарубежные, ~203 тыс. правил, 5,3 МБ, тег `ADS-GLOBAL`) и `geosite_ADS-RU.dat` (российские зоны и свои дополнения, ~1,4 тыс. правил, тег `ADS-RU`). Источники: runetfreedom (`category-ads-all`), AdGuard DNS filter, Peter Lowe's list; база хранится текстом в отдельном репозитории `OpenWRT-VM-PROXY-ads` (лицензия GPL-3.0). Включение: `ADS_GEOSITE_GLOBAL=1`, `ADS_GEOSITE_RU=1` в `/etc/pw2-routing.conf`.
- `pw2-geosite refresh` пересобирает `geosite.dat` из чистой основы и всех файлов `data/`; новый манифест `/etc/pw2-geosite.tags` помнит ранее подключённые теги (в том числе устаревший `RU-ADS`), поэтому после смены набора баз старые списки не остаются в файле.
- Память: Xray с большой базой занимает ~50 МБ на процесс; рекомендуется ОЗУ VM 384 МБ (`vm-tune.ps1 -MemMB 384`). Применение правил занимает до минуты.
- Реклама, встроенная в тот же домен, что и сам сайт (YouTube, Авито), по-прежнему не блокируется - оставьте uBlock Origin в браузере.
- Шаг обновления: `1.2.x → 1.3.0` (удаляет `geosite_RU-ADS.dat`, подключает две новые базы, применяет правила).

## 1.2.0 — 2026-10-06
- Российская база рекламы: список `category-ads-all` из `runetfreedom/russia-v2ray-rules-dat` (~149 тыс. доменов, файл `data/geosite_RU-ADS.dat`, 3,8 МБ, тег `RU-ADS`) подключается правилом блокировки (`ADS_GEOSITE_RU=1`). - Исправлено: список рекламы мог склеиться в одну строку и не давал запуститься Xray (ловилось на тестовой копии).
- Шаг обновления: `1.1.0 → 1.2.0` (загружает базу, включает `ADS_GEOSITE_RU`, применяет правила).
