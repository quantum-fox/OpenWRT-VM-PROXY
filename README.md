# Прокси-шлюз на OpenWrt + PassWall2 (VirtualBox, Windows)

> **English summary.** A ready-to-use proxy router for Windows + VirtualBox: an OpenWrt VM running PassWall2/Xray that pulls your provider's subscription, picks the fastest node, gives you a second "work" proxy exit through your own server (with automatic backup), applies RU/UA/CN routing rules, blocks ads and trackers, disables IPv6, and can act as a transparent gateway for Windows (with fail-open). Choose **variant A** (build from scratch with scripts) or **variant B** (import a ready image from the Releases page). Updating an existing install: [docs/update.md](docs/update.md). Documentation is in Russian. License: MIT (the bundled Russian ad-list data file is GPL-3.0, see [NOTICE.md](NOTICE.md)).


Готовый к сборке «умный» интернет-шлюз: виртуальный роутер, который
- берёт узлы из **подписки** вашего провайдера, сам обновляет её и выбирает самый быстрый узел (**пул**);
- даёт **два прокси** для программ: `1080/8080` (общий, через пул) и `1081/8081` (**рабочий**: через пул на **ваш** сервер — выход с вашим постоянным IP);
- умеет заворачивать **весь** трафик Windows через себя (прозрачный шлюз) и сам отключается, если роутер упал;
- применяет **правила по странам** (RU, UA, CN), блокирует UA на уровне файрвола и сам переключает рабочий выход на запасной узел, если ваш сервер недоступен.

Что именно делает каждый порт и правило — [docs/architecture.md](docs/architecture.md). Текущая версия — файл `VERSION`; уже установили раньше — [docs/update.md](docs/update.md).

## Что понадобится
- **Windows 10/11 (64 бит)**, права администратора, ~4 ГБ свободного места, свободные ~400 МБ ОЗУ для VM.
- **VirtualBox 7.x** (проверено на 7.2.2), установленный в `C:\Program Files\Oracle\VirtualBox`.
- Работающий интернет на компьютере (Wi-Fi или кабель — роутер выйдет в него «мостом»).
- **Адрес подписки** провайдера (ссылка `https://…`, отдающая узлы VLESS/VMess и т. п.).
- **Ссылка `vless://…` вашего собственного сервера** (например, VPS с панелью 3x-ui, протокол VLESS + Reality): через него идёт рабочий выход `1081/8081`. Без него работает всё остальное, кроме рабочего порта.
- PowerShell-скрипты запускайте от администратора; если политика выполнения мешает — используйте `.cmd`-обёртки или `powershell -ExecutionPolicy Bypass -File …`.

## Безопасность — прочитайте
- В поставке **нет** чужих секретов: подписки, серверы и пароли — ваши, вводятся вами. В образе только заглушки (`203.0.113.x`, `example.invalid`).
- **Пароль root образа по умолчанию — `pw2-change-me`.** Команда `pw2-setup` при первом запуске требует сменить его. До смены не подключайте роутер к недоверенной сети (LAN роутера — отдельный Host-Only адаптер, снаружи недоступен).
- У прокси-портов **нет логина и пароля** (PassWall2 их не поддерживает) — они слушают только внутреннюю сеть роутера `10.99.77.0/24`; со стороны WAN закрыты файрволом.
- Файл `/root/secrets.env` на роутере (подписка, ссылки на серверы) доступен только root. **Не публикуйте и не пересылайте его**, как и любые `vless://`-ссылки и адрес подписки: они содержат ключи доступа.
- Образ — «снимок» чужой сборки: если важна полная уверенность, выбирайте вариант A (всё ставится из официальных источников).
